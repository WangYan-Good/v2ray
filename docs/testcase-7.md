## 背景

当前 `install.sh` 使用 `&` + `wait` 进行并行下载：

```bash
# 第 590-599 行
[[ ! $is_core_file ]] && { download core & msg ok "  - 开始下载 Xray 核心"; }
[[ ! $local_install ]] && { download sh & msg ok "  - 开始下载脚本"; }
[[ $jq_not_found ]] && { download jq & msg ok "  - 开始下载 jq"; }
get_ip
wait
check_status
```

**问题**:
1. 多个后台下载任务共享同一个 `$tmpdir`，可能互相覆盖临时文件
2. `wait` 无法区分哪个下载失败，只能等待全部完成
3. 单个下载失败后其他任务仍继续，但 `check_status` 只检测最终状态
4. 无下载超时和重试机制，单个卡住会阻塞全部
5. 后台任务的 stdout/stderr 可能交叉输出，日志混乱

**修复方案**:
- 使用顺序下载替代 `&` 并行 (简单可靠)
- 每个下载任务添加独立状态标记文件
- 添加下载超时 (30s) 和重试机制 (最多 3 次)
