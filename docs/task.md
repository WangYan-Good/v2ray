**问题描述**:
`VLESS-XTLS-uTLS-REALITY` 协议在 `protocol_list` 中被注释，底层 JSON 生成逻辑已实现但未启用。

**影响文件**:
- `src/core.sh` (第 13 行, 第 1111-1112 行, 第 1160-1161 行)

**具体任务**:
- [x] 1.1 取消 `protocol_list` 中 `VLESS-XTLS-uTLS-REALITY` 的注释
- [x] 1.2 取消 `add` 函数中 reality 分支的注释 (第 1111-1112 行)
- [x] 1.3 取消协议匹配中 `*reality*` 分支的注释 (第 1160-1161 行)
- [x] 1.4 测试 REALITY 协议的 add/info/del 流程
- [x] 1.5 验证客户端连接 (xtls-rprx-vision 流控)

**验收标准**:
- ✅ `xray add reality` 能成功生成配置
- ✅ `xray info` 能正确显示 publicKey/serverName
- ✅ 客户端可正常连接

**修改摘要**:
```diff
# src/core.sh

# 1. protocol_list 中启用 REALITY
-    # VLESS-XTLS-uTLS-REALITY
+    VLESS-XTLS-uTLS-REALITY

# 2. add 函数中启用 reality 分支
-    # r | reality)
-    #     is_new_protocol=VLESS-XTLS-uTLS-REALITY
-    #     ;;
+    r | reality)
+        is_new_protocol=VLESS-XTLS-uTLS-REALITY
+        ;;

# 3. 协议参数匹配中启用 reality 分支
-    # *reality*)
-    #     is_reality=1
-    #     is_use_port=$2
-    #     is_use_uuid=$3
-    #     is_use_servername=$4
-    #     ;;
+    reality)
+        is_reality=1
+        is_use_port=$2
+        is_use_uuid=$3
+        is_use_servername=$4
+        is_add_opts="[port] [uuid] [servername]"
+        ;;
```

**技术说明**:
- REALITY 协议不需要域名 (域名由 serverName 字段替代)
- 自动生成 X25519 密钥对 (publicKey/privateKey)
- 使用 xtls-rprx-vision 流控
- 支持短 ID (shortIds) 配置
- 客户端指纹默认为 ios

- [x] 2.4 测试 XHTTP 多路复用功能

**验收标准**:
- ✅ `xray gen vless-xhttp-tls domain` 成功, mode="auto"
- ✅ Nginx 配置正确 (共用 H2 反向代理模板)

**修改摘要**:
```diff
# src/core.sh

# 1. protocol_list 中启用 XHTTP
+    VLESS-XHTTP-TLS
+    Trojan-XHTTP-TLS

# 2. add 函数中启用 xhttp 参数分支
+    *-xhttp-tls)
+        is_xhttp=1
+        is_use_port=$2
+        is_use_uuid=$3
+        is_use_host=$4
+        is_use_path=$5
+        is_add_opts="[port] [uuid] [host] [path]"
+        ;;

# 3. get protocol 中修复 *xhttp* 匹配顺序
+        *xhttp*)   # 必须放在 *http* 之前
+            net=xhttp
+            is_stream='...mode:"auto"...'
+            ;;
+        *h2* | *http*)
+            net=xhttp
+            is_stream='...mode:"stream-one"...'
+            ;;

# 4. 快捷输入支持
+        vxhttp | txhttp)
+            is_new_protocol=...
+            ;;
```

**测试结果**:

- Google: ✅ HTTP/2 200

**验收标准**:
- ✅ 多次运行安装脚本不出现竞态条件
- ✅ 单个下载失败时不影响其他任务 (顺序下载)
- ✅ 测试用例 testcase-7.md 通过

**修改摘要**:
```diff
# install.sh

# 旧代码: 并行下载 (竞态条件)
- [[ ! $is_core_file ]] && { download core & msg ok "  - 开始下载 Xray 核心"; }
- [[ ! $local_install ]] && { download sh & msg ok "  - 开始下载脚本"; }
- [[ $jq_not_found ]] && { download jq & msg ok "  - 开始下载 jq"; }
- get_ip
- wait

# 新代码: 顺序下载 (避免竞态)
+ if [[ ! $is_core_file ]]; then
+     msg warn "  - 开始下载 Xray 核心..."
+     download core
+     msg ok "  - Xray 核心下载完成"
+ fi
+ if [[ ! $local_install ]]; then
+     msg warn "  - 开始下载脚本..."
+     download sh
+     msg ok "  - 脚本下载完成"
+ fi
+ if [[ $jq_not_found ]]; then
+     msg warn "  - 开始下载 jq..."
+     download jq
+     msg ok "  - jq 下载完成"
+ fi
+ get_ip
```

**测试结果**:
- 服务端全新安装: ✅ 顺序下载，无竞态
- 服务端重复安装: ✅ 顺序下载，无竞态
- 下载重试: ✅ wget -t 5 已实现
